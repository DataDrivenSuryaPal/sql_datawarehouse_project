# ============================================================
# 3. DATA WAREHOUSE ARCHITECTURE
# ============================================================

The data warehouse follows a three-layer architecture:

BRONZE LAYER
-------------
Purpose:
- Store raw source data
- Preserve the original structure of source files
- Perform minimal transformation
- Maintain source-level data traceability

Characteristics:
- Raw data
- No business transformations
- Full data ingestion
- Source-oriented tables


SILVER LAYER
------------
Purpose:
- Clean and standardize data
- Resolve data quality issues
- Apply technical transformations
- Prepare data for business modeling

Typical operations:
- Data cleansing
- Data type conversion
- Handling NULL values
- Duplicate removal
- Standardization
- Data validation
- Column renaming
- Derived attributes
- Data consistency checks


GOLD LAYER
----------
Purpose:
- Store business-ready data
- Support reporting and analytics
- Provide optimized analytical datasets

Characteristics:
- Business-friendly structure
- Fact and dimension tables
- Integrated data
- Aggregations and KPIs
- Ready for reporting and analysis


# ============================================================
# 4. ETL REQUIREMENTS
# ============================================================

ETL Process:
- Extract
- Transform
- Load

EXTRACT
-------
- Full extraction from CRM CSV files
- Full extraction from ERP CSV files
- Validate source files
- Load source data into Bronze layer
- Preserve source data for traceability


TRANSFORM
---------
- Standardize column names
- Convert data types
- Handle missing values
- Remove duplicate records
- Validate business keys
- Standardize date formats
- Standardize text values
- Apply business rules
- Generate derived columns
- Perform data quality checks


LOAD
----
- Load cleaned data into Silver layer
- Integrate data from multiple source systems
- Load business-ready data into Gold layer
- Maintain referential integrity
- Generate surrogate keys where required
- Support full-load processing

# ============================================================
# 9. DATA WAREHOUSE KEYS
# ============================================================

The project should distinguish between:

Business Keys:
- Keys originating from source systems
- Used to identify source records

Surrogate Keys:
- Warehouse-generated identifiers
- Used as primary keys in dimension tables
- Used to establish relationships with fact tables
